Planning assistant

Pick a topic, a sector, and how much time you have, and this assembles a DARE session outline from a growing library of blocks I've written and tested, not a model guessing what a good session looks like. It now spans web and API flaws, network and Active Directory attacks, cloud, wireless, malware, blue-team detection and more, so you can plan a DARE session for almost any cybersecurity topic. Where a topic isn't specialised for your sector yet, it says so and gives you the general version rather than inventing one.

Pick a vulnerability, a sector, and a time budget, then build the outline.
